# wizard-defense-privacy

Página pública da **política de privacidade** do jogo Wizard Defense
(`com.caiog.wizarddefense`), exigida pela ficha da Google Play Store.

Este repositório existe **só** para hospedar essa página. Ele é público de
propósito: a Play Console exige uma URL de política acessível sem login. Nenhum
código, documento interno ou material do projeto entra aqui.

## Como publicar

1. Settings → Pages → Source: **Deploy from a branch** → branch `main`, pasta `/ (root)`.
2. A URL sai como `https://<usuario>.github.io/wizard-defense-privacy/`.
3. Essa URL vai no campo de política de privacidade da ficha da Play Console.

## Conteúdo

- `index.html` — a página publicada: inglês primeiro (`#en`), português abaixo
  (`#pt`), na mesma URL cadastrada no AdMob e na Play Console.

A fonte editorial deste texto vive em `docs/privacy-policy.en.md` e
`docs/privacy-policy.md`, no repositório privado do jogo. **Ao mudar lá, replicar
aqui** — a versão que vale juridicamente é a que está publicada nesta página.
